# Visha: The Last Guardian

A 2D turn-based combat game built with Unity and C# for SER594:Game Programming
and Design, Team 5.

Play as Vishakanya, a poison specialist reclaiming a cursed temple. 
Read enemy intentions, build poison with Venom Strike, consume it with Serpent’s Bite, 
and use Fade to reduce incoming damage.

## Run Locally

1. Clone the repository.
2. Add the project folder in Unity Hub.
3. Open it with Unity 6000.6.3f1.
4. Follow the scene setup and launch instructions included in the project.
